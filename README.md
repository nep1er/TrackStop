В рамках данного проекта разрабатывается десктопное приложение - музыкальный плеер и сервис управления музыкальной библиотекой, функционирующий на основе локальной базы данных. 

Приложение сочетает в себе элементы классического музыкального плеера и современных стриминговых сервисов, предоставляя пользователям возможность прослушивания музыки, работы с альбомами и исполнителями, а также персонализации контента без использования удалённых серверов.


Разрабатываемая система поддерживает несколько ролей пользователей, включая обычных пользователей, исполнителей и администратора, что позволяет реализовать разграничение прав доступа, управление контентом и администрирование сервиса
